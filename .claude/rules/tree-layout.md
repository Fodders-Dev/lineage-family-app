# Layout дерева: хрупкие места

`_enforceContiguousSubtreeBlocks` — финальный X-проход раскладки, он ДЕЛИКАТНЫЙ:

- «Мостовые» пары (супруги, у каждого свои предки) упорядочиваются к КРАЮ
  блока в сторону другой семьи по структурному ключу B4 (не по жадному
  centerX), затем UNCLAMPED-сдвиг к середине родителей, чтобы пара
  «straddle'ила» границу.
- После — left→right separation sweep по уровням (глубочайшие первыми)
  гарантирует отсутствие перекрытий по построению (B2). Edge-aware порядок и
  sweep — неразделимая пара: менять одно без другого нельзя.
- Ложные корни (B3) пересаживаются к родителям.

**Любое изменение здесь** обязано пройти
`flutter test test/interactive_family_tree_test.dart` (32 теста, включая
регресс divorced-couple) до коммита.

Голден-эталоны painter'а — из Linux-CI; локальные падения на Windows ~2% —
среда, не регресс (регенерация только workflow'ом `regen-tree-goldens.yml`).
